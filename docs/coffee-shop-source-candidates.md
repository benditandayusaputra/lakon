## Source notes from docs/BISINDO_AGENT_GUIDE.md (verified 1 Sep 2026)

- The Pusbisindo dictionary (<https://www.pusbisindo.org/kamus-kosa-isyarat>)
  is currently **empty** — its main content element contains no entries at
  all. Pusbisindo remains the validation path (contact:
  pusat@pusbisindo.org / WA on the site), not a direct clip source.
- Balai Bahasa Jatim has ±150 sign-vocabulary videos (one word per video,
  direct MP4, genuine signs — verified) including SATU–SEMBILAN, MINUM,
  PANAS, DINGIN, BESAR, KECIL, MANIS, PAHIT — but does NOT have: halo,
  kopi, pesan, mau, berapa, bayar, terima kasih. All East Java variant.
  Its clip pattern: ±2s silence → sign → silence; the silent portion is
  automatically discarded on import (frames without hands are skipped).
